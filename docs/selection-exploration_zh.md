# 选区浮窗探索

在 Markdown 笔记中选中文字后点击 **Ask for AI**。浮窗使用选区所属的完整笔记作为上下文，以 Markdown 显示回答；接口支持时会流式输出。

在任意回答中选中文字，点击 **继续解释**；或使用该栏生成的探索问题和追问输入框。新回答会追加到已有回答之后，空间不足时自动换行。探索问题由模型根据对应回答生成；如回答未附带有效建议，插件会基于该回答补充请求，失败时可重试。

浮窗可以通过标题栏拖动，通过右下角调整大小。点击 **保存** 将当前对话快照保存到原笔记所在文件夹，已有文件不会被覆盖；生成中保存只包含当时已有的内容。

选区、所属笔记全文、追问和相关回答会发送给当前配置的模型服务。关闭浮窗会取消正在运行的请求。

此分支基于 Quick Ask 1.0.7，包含用户定制的下游修改；上游 `release:check` 的来源校验会拒绝这些修改，不应将此分支作为原上游同步发布。

选区解释按“是什么、为什么设计、如何用”组织。资料不足时，模型可以调用 Quick Ask 已配置的搜索服务，并尽可能列出来源；模型自行判断是否搜索，无法保证每次都调用。搜索不可用或未找到可靠证据时会提示，请检查搜索设置。搜索查询可能发送所选主题的关键词，请勿选取不适合发送给搜索服务的敏感内容。

当配置的 DuckDuckGo 搜索发生网络错误、超时、验证挑战或结果无法解析时，插件会自动用 Bing 重新搜索同一查询；因此查询会发送给 Bing。界面会显示实际返回结果的服务。若两个服务均不可用，请检查网络或配置其他搜索服务。
